# Machine Learning Atlas — SEO Strategy

## Brand and primary search intent
Brand: **Machine Learning Atlas (ML Atlas)**  
Primary homepage phrase: **Learn Machine Learning Visually**

The site targets natural, high-intent search families rather than keyword stuffing:
- machine learning
- learn machine learning
- machine learning tutorial
- machine learning algorithms
- machine learning for beginners
- machine learning roadmap
- mathematics for machine learning / math for machine learning
- machine learning visualization / interactive machine learning
- linear regression tutorial
- logistic regression tutorial
- KNN / K nearest neighbors
- decision tree machine learning
- random forest machine learning
- support vector machine / SVM
- K means clustering
- DBSCAN clustering
- hierarchical clustering
- PCA machine learning
- ridge regression / lasso regression
- supervised learning / unsupervised learning
- gradient descent
- overfitting and regularization
- which machine learning model should I use

## On-page SEO architecture
- One crawlable HTML URL per algorithm.
- Unique title and meta description per model.
- Absolute canonical links.
- Open Graph + Twitter cards.
- TechArticle / DefinedTerm JSON-LD on model pages.
- LearningResource / DefinedTermSet schema on curriculum pages.
- Semantic heading hierarchy and descriptive internal links.
- Sitemap and robots.txt generated during build.
- Human-readable slugs such as `/pages/linear-regression.html`.
- Internal topic clusters: Algorithms ↔ Math ↔ Roadmap ↔ Compare ↔ Selector ↔ Glossary.

## Important note
Exact monthly keyword volumes are intentionally not claimed here. Search volume varies by geography, time and data provider. The build uses established high-intent phrases and can later be refined with Google Search Console data after launch.
