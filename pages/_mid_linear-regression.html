02 The Problem

An agent asks: how much is this house worth? She has past sales as (size, location, price). Under-price and the seller leaves; over-price and holding costs pile up. The target is a continuous number recoverable only above the noise of features never fully captured.

03 Why It Matters

Regression is the engine behind pricing, demand, risk and dosage. Most "soft" quantities depend linearly on a few drivers, and a fit whose slope reads aloud ("each extra sq ft is \$137") is fast, auditable, and regulator-friendly.

04 Intuition

Points scatter but tilt. Linear regression is the straight line minimising the total squared vertical distance to every point. Each coefficient then reads: the marginal effect of that feature, holding the rest fixed.

05 Mathematical Foundation

Residuals \(e_i = y_i - \hat{y}_i\); cost \(J=\tfrac{1}{n}\sum e_i^2\). Squaring makes a smooth, convex bowl — the unique global minimum is where calculus lands.

06 The Equation

\[ \hat{y}_i = \beta_0 + \beta_1 x_i, \qquad J=\frac{1}{n}\sum_{i=1}^{n}(y_i-\hat{y}_i)^{2} \]
  • \(x_i\) input feature for example \(i\)
  • \(y_i\) observed target
  • \(\hat{y}_i\) prediction
  • \(\beta_0\) intercept — \(\hat{y}\) at \(x=0\)
  • \(\beta_1\) slope — change in \(\hat{y}\) per unit \(x\)
  • \(J\) mean squared error

07 How It Learns

  1. Start anywhere. Guess \(\beta_0=\beta_1=0\).
  2. Feel the slope. \(\nabla J=(-\tfrac{2}{n}\sum e_i,\;-\tfrac{2}{n}\sum e_i x_i)\).
  3. Step downhill. \(\beta \leftarrow \beta - \eta\,\nabla J\).
  4. Stop at bottom. The normal equations reach this point in one shot.

08 Algorithm

Data \((x_i,y_i)\)
↓
Guess \(\beta_0,\beta_1\)
↓
Gradient descent → optimum
↓
\(\hat{y}=\beta_0+\beta_1 x\)

10 Worked Example

Data \((1,1),(2,3),(3,2),(4,5),(5,5)\). \(\bar x=3,\bar y=3\), \(s_{xx}=10,s_{xy}=12\). So \(\beta_1=1.2,\beta_0=-0.6\). Model \(\hat{y}=-0.6+1.2x\). Predict \(x=6\): \(\hat{y}=6.6\).
